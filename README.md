# 👻 GopherGhost
Kiroween 2026, **Resurrection** category. Brings Gopher (RFC 1436) back from the dead as a haunted CRT reader that turns modern web pages into clean Gopher menus.

## Run
```
npm install
npm run dev     # http://localhost:3000
npm test        # unit + property-based tests
```
`/api/browse?url=<url>&raw=1` returns a genuine Gopher menu as text.
